## 项目简介

这是一个基于 LangChain 的 Agent 系统学习项目，采用 **TDD（测试驱动开发）** 方式构建。

### 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│                          Agent                              │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐       │
│  │   LLM   │  │  工具    │  │  记忆    │  │  规划    │       │
│  │ (决策)  │  │ (执行)  │  │ (存储)  │  │ (分解)  │       │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘       │
└─────────────────────────────────────────────────────────────┘
```

### 工作流程

```
规划 -> 决策 -> 执行 -> 结果存入记忆 -> 再决策 -> ... -> 任务完成
```

## 快速开始

### 1. 环境准备

```bash
git clone https://github.com/tripodxu/myselfagent.git
cd myselfagent
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
```

### 2. 配置

复制 `.env.example` 为 `.env` 并修改配置。

### 3. 运行演示

```bash
python examples/demo.py
python main.py --interactive
```

### 4. 运行测试

```bash
pytest -v
pytest --cov=src
```

## 模块详解

### 1. LLM 模块 (src/llm.py)

自定义LLM类，连接本地API，支持自动重试和超时处理。

### 2. 工具系统 (src/tools/)

- **Python执行工具**: 安全执行Python代码，限制危险模块导入
- **文件IO工具**: 文件读写操作，路径安全检查
- **搜索工具**: 文本搜索，支持正则表达式

### 3. 记忆系统 (src/memory/)

缓冲记忆实现，支持自动持久化到JSON文件和上下文窗口管理。

### 4. 规划模块 (src/planner/)

简单规划器，将目标分解为步骤，跟踪进度。

### 5. Agent 核心 (src/agent.py)

整合所有模块，实现规划->决策->执行->记忆->再决策的循环。

## TDD 学习笔记

### 什么是 TDD？

1. **Red**: 先写失败的测试
2. **Green**: 写最少的代码让测试通过
3. **Refactor**: 重构代码
